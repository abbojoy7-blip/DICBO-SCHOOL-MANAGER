# DICBO School Manager - Release Notes

## Version 1.0.0 (Initial Production Release)
**Release Date**: August 2026

### Features
- **Secure Authentication**: JWT-based login with Role-Based Access Control (RBAC).
- **Student Management**: Full CRUD operations for student profiles, including auto-generated admission numbers.
- **Academic Structure**: Configurable academic years, terms, classes, and streams.
- **Attendance Tracking**: Digital register for teachers to mark and monitor student attendance.
- **Fee Management**: Professional fee recording with automated receipt generation and balance tracking.
- **Reporting Center**: Detailed financial and enrollment reports with PDF/Print support.
- **Staff Management**: Admin dashboard to manage employee accounts and permissions.
- **Audit System**: Activity tracking for all critical system changes.
- **Data Protection**: Built-in backup and export tools.
- **Responsive UI**: Optimized for desktops, tablets, and mobile devices.

### System Requirements
- **Server**: Node.js v16+, MongoDB v5+
- **Client**: Modern web browser (Chrome, Firefox, Safari, Edge)
- **Memory**: Minimum 4GB RAM recommended for the host server.
