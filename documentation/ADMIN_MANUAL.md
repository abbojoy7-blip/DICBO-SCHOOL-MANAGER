# DICBO School Manager - Administrator Manual

## Getting Started
1. **Login**: Access the system via the provided URL. Use your administrative credentials.
2. **Setup Academic Year**: Go to **Settings** and ensure the current Academic Year and Term are set correctly.
3. **Manage Staff**: Go to **Staff Directory** to create accounts for teachers, accountants, and other staff members.

## Core Operations
### 1. Registering Students
- Navigate to **Students**.
- Use the **Add Student** button to register new admissions.
- Fill in personal, parent, and academic details.

### 2. Managing Classes
- Use the **Classes** module to define standard classes (e.g., Primary One, Secondary Three).
- Assign teachers to their respective classes.

### 3. Monitoring Reports
- Access the **Reports** module to view school-wide analytics.
- View enrollment trends and financial collection summaries.

## System Maintenance
### 1. Data Backup
- It is recommended to perform a backup weekly.
- Go to the **Backup** section (or use the export tool) to download a JSON snapshot of the database.
- Store this file in a secure, off-site location (e.g., Google Drive or a USB drive).

### 2. Security
- Never share administrative passwords.
- Deactivate staff accounts immediately if a staff member leaves the school.
- Monitor the **Audit Logs** to review critical system actions.

## Troubleshooting
- **Cannot Login**: Verify the backend server is running and the database is connected.
- **Reporting Errors**: Ensure all students are correctly assigned to classes and academic years.
